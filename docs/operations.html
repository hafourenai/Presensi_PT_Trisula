Operasional harian

Perintah aman untuk membuka server, memperbarui aplikasi, membaca log, dan melakukan rollback.

Di halaman iniMasuk VPSUpdateStatus & logRestartRollback

Masuk ke VPS

ssh -p PORT_SSH USER_VPS@IP_VPS
cd /opt/presensi/Presensi_PT_Trisula

Update dari GitHub

  1. Pastikan branch dan working tree benar.
    git status
  2. Ambil commit terbaru tanpa merge otomatis.
    git pull --ff-only origin main
  3. Bangun dan ganti container.
    docker compose build
docker compose up -d app --remove-orphans
  4. Periksa hasil.
    docker compose ps
docker compose logs --tail=100 app

Status, log, dan resource

docker compose ps
docker compose logs -f --tail=100 app
docker stats --no-stream
df -h
docker system df

Tekan Ctrl+C untuk keluar dari log tanpa menghentikan container.

Restart dan pemeliharaan

docker compose restart app
docker image prune -f

Jangan menjalankan docker compose down -v; opsi tersebut dapat menghapus volume persisten.

Rollback

git log --oneline -10
git checkout COMMIT_STABIL
docker compose build
docker compose up -d app
docker compose ps

Setelah investigasi selesai, kembali dengan git switch main.
