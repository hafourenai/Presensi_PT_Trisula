Referensi pemulihan

Temukan masalah dari gejalanya.

Mulai dari pemeriksaan yang aman sebelum mengubah atau menghentikan service.

MasalahBuild gagalTidak healthyPort terpakaiDomain 404HTTPS

Build gagal karena environment

git pull --ff-only origin main
docker compose config --quiet
docker compose build

Jangan memasukkan secret sebagai build argument. Client Supabase admin telah diubah agar dibuat saat runtime.

Container tidak healthy

docker compose ps
docker compose logs --tail=200 app

Periksa nama environment, koneksi Supabase, serta error startup.

Port sudah digunakan

ss -lntp | grep ':PORT '

Jangan menghentikan service yang tidak dikenal. Pilih port loopback kosong dan ubah APP_PORT.

Domain menghasilkan 404

curl -I -H "Host: presensi.example.com" http://127.0.0.1/login
nginx -t
systemctl reload nginx

Periksa DNS, nama server_name, symlink sites-enabled, dan konfigurasi domain pada provider VPS.

HTTPS bermasalah

certbot certificates
certbot renew --dry-run
tail -n 100 /var/log/letsencrypt/letsencrypt.log

Pastikan DNS benar dan port 80/443 dibuka firewall.
