Build aplikasi

Persiapkan environment dan hasilkan image produksi tanpa memasukkan secret ke build context.

Di halaman iniEnvironmentValidasiBuild imageHasil

1. Siapkan environment

cp .env.example .env
nano .env
chmod 600 .env

Isi menggunakan nilai produksi. Jangan menyalin `.env` ke Git, image, screenshot, atau chat.

DOMAIN=presensi.example.com
APP_PORT=3002
PUBLIC_SUPABASE_URL=https://PROJECT_REF.supabase.co
PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxx
SUPABASE_SECRET_KEY=sb_secret_xxx

2. Validasi Compose

docker compose config --quiet

Perintah berhasil bila tidak menghasilkan output. Jangan gunakan `docker compose config` tanpa `--quiet` saat membagikan hasil karena nilai environment dapat ikut tercetak.

3. Bangun image

docker compose build

Build pertama membutuhkan waktu lebih lama. Warning Svelte tidak menghentikan build; perhatikan baris terakhir dan exit code.

4. Verifikasi image

docker image ls presensi-app

Image siap digunakan jika bernama presensi-app:latest dan proses build berakhir dengan status sukses.
