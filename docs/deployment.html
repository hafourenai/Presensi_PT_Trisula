Deployment pertama

Jalankan container, hubungkan Nginx, terbitkan HTTPS, lalu arahkan Supabase Auth.

Di halaman iniDNSContainerNginxHTTPSSupabase

1. Arahkan DNS

Nama: presensi
Tipe: A
Nilai: IP_VPS
TTL: 3600
nslookup presensi.example.com

2. Jalankan aplikasi

docker compose up -d app --remove-orphans
docker compose ps
curl -I http://127.0.0.1:3002/login

Status container harus healthy dan endpoint lokal menghasilkan HTTP 200.

3. Konfigurasi Nginx

server {
    listen 80;
    server_name presensi.example.com;
    client_max_body_size 10m;
    location / {
        proxy_pass http://127.0.0.1:3002;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
nginx -t
systemctl reload nginx

4. Terbitkan HTTPS

certbot --nginx -d presensi.example.com
certbot renew --dry-run

5. Atur Supabase Auth

Site URL:
https://presensi.example.com

Redirect URL:
https://presensi.example.com/**

Selesaikan dengan membuka halaman login melalui HTTPS dan menguji akun administrator.
